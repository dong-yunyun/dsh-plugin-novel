# M18 内容策略全量扫描

---

## 一、三层检查

| 层 | 查什么 | 判定 |
|---|---|---|
| 卡片 | 所有字符串字段里是否出现词表词 | 命中即失败（机器产物，应为零） |
| `contentRedactions` | 行区间是否合法（`1 ≤ start ≤ end ≤ 章行数`） | 非法即失败 |
| 产物 | 概要 / 续写包 / 剧本包里是否出现词表词 | 只提示**人工复核**，不算失败 |

为什么产物不算失败：散文里"高潮"正常指剧情高潮，词表必然误伤。这条在 §3.2 就写明了——**词表既漏又误，不能当判据**。

---

## 二、词表设计

`sanitize/terms.txt`，外置可改，**6 条**起步：

```
性交 / 做爱 / 口交 / 阴茎 / 阴道 / 高潮
```

文件头写死了三条注意事项：

1. 不是主判据，主判据是内容判断
2. 必然漏（隐喻、代称、纯动作白描抓不到）
3. 必然误伤（"插入""进入"在战斗/雨天场景里正常）

所以扫描结果只用来**发现"模型漏判或标注漏写"**，不用来判定违规。
