## 本轮收尾完成的两项

### ① M14 自包含扫描器

`scanSelfContained(md)` 已进 `workflow.mjs`，规则五条：

| 规则 | 说明 |
|---|---|
| `cards/` | 引用卡片目录路径 |
| `ch\d{4}\.json` | 引用卡片文件名 |
| `F-\d+-\d+` | 暴露内部伏笔 ID |
| `[A-Za-z]:[\\/]` | 绝对路径 |
| `nodes/manifest/bible/graph.json` | 引用内部产物名 |

已接入回归脚本，概要 + 剧本各查一遍，**均 0 命中**。这条从"未做"变成"自动可回归"。

### ② 伏笔 thread id

| 层 | 改动 |
|---|---|
| 数据结构 | `planted` 支持 `{id, desc}`；无 id 时按 `F-{章号}-{序号}` 自动分配 |
| `paid` | 支持 `{id}` 或字符串；解析顺序：精确 id → 包含匹配 → 二元组相似度（阈值 0.25） |
| Bible | 新增 `paidThreads` 与 `unresolvedPaid` 计数 |

**结果：66 条伏笔中 2 条被正确回收，4 条标签未解析。**

回收明细：

- `F-2-1` 第 2 章「BOS 网吧被反复强调，为楚南行出场铺路」
- `F-4-1` 第 4 章「Lulu 的人脉与好胜」

**这一步还顺手修了 2 条错标**：ch4 的「第三章的友谊赛」和 ch84 的「蓝星的来历」原本被记成"回收"，其实一个是事件、一个是背景揭示，都不是伏笔回收，已清空。

> 阈值踩坑记录：第一版用 0.12，跑出 4 条回收，其中 2 条是假阳性（把"Lulu 几乎认定方少云会输""湖大校队实力成谜"错配成了已回收）。收紧到 0.25 后剩 2 条真回收、4 条未解析。**宁缺勿滥**——错报"已回收"比漏报更损害可信度。
