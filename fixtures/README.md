# 样本投放区

把小说文本放到这个目录，W1 的切分器就以它为真实输入开发与验证。

## 放什么

| 优先级 | 内容 | 说明 |
|---|---|---|
| 必需 | **1–2 章正文** | 只要真实格式，不要清洗。原样最好 |
| 可选 | **连续 10–20 章** | 用于验证卷/分卷、番外、作者的话的边界 |
| 可选 | **整本** | 只在验证规模时用；单个文件，不要再拆 |

## 怎么放

- 直接当文件丢进来即可，UTF-8 编码，`.txt` 或 `.md` 都行。
- 如果文件在别的盘，**告诉我绝对路径**，我来复制，你不用手动搬。
- 文件名随意，但别用中文空格混排。

## 我需要从样本里看出的东西

这些直接决定切分器和实验 0 的门槛，逐条对应设计文档 §3.1 与 §9：

1. **章节标题格式**——「第37章」「第三十七章」「Chapter 37」「37.」还是根本没有标题
2. **段落结构**——是"每段一行"还是"整章一个大段落"（后者会让 `read` 的行寻址失效，见 §6.4）
3. **番外 / 作者的话 / 卷标** 有没有、长什么样
4. **系统面板、属性面板** 这类模板化文本的形态与占位
5. **对话占比** 与引号风格（「」还是“”）
6. 有没有 BOM、全角空格、诡异换行

## 我不会做的事

- 不上传、不外发；文本只留在本工作区。
- 不改动 `.` 下与 `novel-plugin\` 无关的任何文件。

## 放好之后

我会先产出三件东西给你看，而不是继续写文档：

1. `manifest.json` —— 切分结果（章数、行区间、场景边界、内容哈希）
2. `chapters/chNNNN.md` —— 物理切分产物
3. `cards/chNNNN.json` —— 前 3 章的卡片，供你按 M6 的标准挑刺
